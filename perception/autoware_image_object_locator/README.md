# autoware_image_object_locator

<a id="purpose"></a>

## 用途

`autoware_image_object_locator` 软件包利用二维图像中检测到的目标生成三维目标检测结果，从而提高感知的稳健性。

| 定位器名称        | 说明                                                    | 详情                                |
| ------------------- | -------------------------------------------------------------- | ------------------------------------- |
| bbox_object_locator | 根据图像中的包围框生成三维目标检测结果。 | [链接](./docs/bbox-object-locator.md) |
