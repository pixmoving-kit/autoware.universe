# tier4_datetime_rviz_plugin

<a id="purpose"></a>

## 用途

此插件在 rviz 中显示 ROS 时间和系统时钟时间（Wall Time）。

<a id="assumptions-known-limits"></a>

## 假设与已知限制

待补充。

<a id="usage"></a>

## 用法

1. 启动 rviz，选择 panels/Add new panel。
   ![select_panel](./images/select_panels.png)
2. 选择 tier4_datetime_rviz_plugin/AutowareDateTimePanel，然后点击 OK。
   ![select_datetime_plugin](./images/select_datetime_plugin.png)
